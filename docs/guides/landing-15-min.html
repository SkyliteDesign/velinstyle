Landing in 15 minutes

Scaffold a runnable page with only CSS classes that exist — then preview and review.

  1. Install / vendor — npm i @birdapi/velinstyle or copy dist/ into vendor/velinstyle. On Windows, prefer the published CLI (pathToFileURL for config imports).
  2. Create — npx velinstyle create landing ./my-landing --theme earth
  3. Serve — npx velinstyle serve ./my-landing (default port 4173)
  4. Compose — velinstyle blueprint split-hero --strict, pricing-band, cookie-consent, empty-state
  5. Doctor — velinstyle doctor (icons sprite, themes, config import)
  6. Review — velinstyle review ./my-landing/index.html --prompt "Marketing landing"

Recipes (no new WCs)

  • Cookie bar → blueprint cookie-consent
  • Empty state → blueprint empty-state
  • Pricing columns → blueprint pricing-band / pricing-table
  • App chrome → blueprint app-chrome

Agents: emit only classes present in CSS; gate with velinstyle blueprint --strict or npm run check:blueprints.
