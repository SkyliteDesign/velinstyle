Marketing lite CSS

Prefer a layer subset over the full bundle when the page only needs tokens, layout, buttons/cards, and spacing/flex utilities.

Preset

velinstyle build --preset lite -o ./velinstyle-lite.css --minify

# Or in velinstyle.config.js:
# export default { preset: 'lite', output: './velinstyle-lite.css', minify: true };

Lite layers: tokens, reset, base, layout, components, utilities (skips a11y / helpers unless you add them).

JS path

Do not ship the full components IIFE for a static marketing page. Prefer:

  • bootFromDOM(document, { attributes: true }) + only the WCs you use, or
  • lazy register() / runtime chunks for form-summary, theme-toggle, etc.

Measure after build: compare velinstyle-lite.css to dist/velinstyle.min.css. Typical minify sizes in 1.2.0: lite ≈ 140 KB vs full ≈ 162 KB (~87%). The CLI prints both sizes after --preset lite and warns if lite is not smaller (e.g. unbundled fallback). Prefer lazy WC / bootFromDOM for JS.
