Ecommerce guide

VelinStyle ships a sample storefront, not a full multipage commerce kit. Use it as a pattern reference; expect custom CSS/JS for cart, filters, and checkout.

Start here

  • Sample: samples/ecommerce.html
  • Scaffold: velinstyle create landing or create dashboard for shells
  • Quality gate: velinstyle check . --profile marketing

What is not included yet

  • velinstyle create shop multipage skeleton (planned)
  • Official product-card / filter-sidebar blueprints as a complete suite
